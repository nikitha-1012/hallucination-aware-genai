## 2. Collection: `cybersecurity_fundamentals`

- **Domain**: Core Cybersecurity Principles and Defenses
- **Source Documents**:
  - `network_security.md`: Firewalls (packet filtering, stateful inspection, proxy), Virtual Private Networks (IPsec, OpenVPN), Intrusion Detection & Prevention Systems (IDS/IPS), and port scanning techniques (TCP SYN, connect scan).
  - `application_security.md`: OWASP Top 10 web vulnerabilities including SQL Injection (SQLi and parameterized query mitigation), Cross-Site Scripting (Stored, Reflected, DOM-based XSS, and contextual output encoding/CSP), and Cross-Site Request Forgery (CSRF tokens and SameSite cookie attributes).
  - `cryptography_and_access_control.md`: Symmetric encryption (AES) vs. asymmetric encryption (RSA, ECC), cryptographic hashing (SHA-256, collision resistance, salted bcrypt password storage), Multi-Factor Authentication (MFA), Principle of Least Privilege, and Role-Based Access Control (RBAC).
- **Authoritative References**:
  - NIST Special Publication 800-Series (e.g., SP 800-41 Rev. 1 Guidelines on Firewalls and Firewall Policy; SP 800-63B Digital Identity Guidelines; SP 800-145 Cloud Computing). U.S. Federal Government publications (Public Domain under 17 U.S.C. § 105).
  - OWASP Foundation (Open Web Application Security Project): OWASP Top 10 Web Application Security Risks and OWASP Cheat Sheet Series.
- **License**:
  - NIST publications: U.S. Public Domain.
  - OWASP material: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0).
